# UI mockup generators (UI chat, 19 Nov 2026)

Scripts that drew the UI Brainstorm's Move and range preview and Enemy preview pages, and Approved UI v3. Not part of the game; nothing here is loaded by the board.

- `lib.js`: builds engine states from a spec, routes (Game Laws 2.11), range discs, spokes, Evade hexes. Uses `../board/engine.js` and `../board/data.js`.
- `draw.js`: the field (hexes, zones, pitch lines, marks, badges, rings, tokens).
- `gen.js`: page shell, top bar, unit panel, buttons, attack drawer, route row.
- `scen*.js` → `scen*.json`, `la11.js`, `sp12.js`: scenario data. `build15.js`: last move-preview round. `buildE4.js`: enemy preview Round 4 and the two redrawn v3 frames.
- Run: `node buildE4.js` (writes `.dc.html` artboards to the `OUT` folder set at the top; change it first).
- Turn cue and field zoom (UI chat, 19 Nov, brief 018): `tc1.js`, `tc2.js`, `tc3.js` (Turn cue Rounds 1–3; `tc3.js` uses `scen13.json`, a hand-placed 13v13 position on brief 014's field), `tz1.js`, `tz2.js` (Field zoom Rounds 1–2). `draw.js` now takes any field size (`S.ncol`, `S.nrow`, `S.centre`), Cavalry icons, `lod` (icons only), `pillScale`, `names` / `centreNames`, and flipped geometry (`G.flipped`).
- Match log (UI chat, 19–20 Nov, brief 018): `ml1.js` … `ml8.js` draw the Match log page, Rounds 1–8 (`ml8.js` = Round 8, approved for build: the log and the specials examples; its overtime examples await the overtime builds). Rows come from a real Brain 5 7v7 game on v3.6, seed `mlog-0`: `mlgame.js` replays it and writes `g0x.json` (log plus per-action Stamina, Command, HP and brace state); `g0.json` is the plain log. Run: `node mlgame.js > g0x.json`, then `OUT=dir/ node ml8.js`.
- Phone fit (UI chat, 20 Nov, for brief 018): `phone-fit/gen.py` draws the UI Brainstorm's Phone fit page, Rounds 1 and 2. Unlike the scripts above it does not redraw the screen: it opens the real board (brief 017's build, served from `board/` on port 8102) in headless Chrome at the Editor's phone size (393 × 665), restyles it (`SLIM` in `mock.py` = Round 1, `SLIM` and `REBUILD` in `mock2.py` = Round 2) and saves the result as static `.dc.html` artboards with every style inlined. Run: `python3 -m http.server 8102` in `board/`, then `python3 gen.py` in `phone-fit/` (needs Python Playwright and Chrome). Round 3: `gen3.py` (with `base.py`) sets up one 7v7 position through the `?shots=1` hook and draws six screens. Round 4: `gen4.py`, the reworked attack preview (two frames). Round 5: `gen5.py`, the same two frames with the Round 4 notes applied. Round 6: `gen6.py`, the last attack-preview tweaks plus the other screens that take field (pull, special, warm-up, end turn, deployment), undesigned. Round 7: `gen7.py`, one sheet for attack, special and flag pull (the pull sheet is rebuilt from the old one), and the warm-up note in the unit bar. Round 8: `gen8.py`, six screens before (the build untouched) and after. Round 9: `gen9.py`, the A/B with full unit names (names in the strip beside the handle).
