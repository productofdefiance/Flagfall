## Brief 030 · Game start

Screens (Approved UI v8) and one set-up rule: squad rules. No rule set, brain or preset changes; every saved match replays as before.

**What the Editor will notice**
- **New game is one screen.** Both sides (Human or Bot, name, era, region; a bot's difficulty and personality), Swap ends, Moves first, **Squad rules**, a Game settings line and the seed with copy and New seed. Then the Lineup screen, then deployment.
- **Squad rules** (Game Laws 2.16): Open, Light only, Heavy only, Foot only, Cavalry only (needs 9v9 or 13v13, so greyed for now) and Random (both lineups drawn from the seed, straight to deployment). The bot picks its own lineup inside the rule.
- **Game settings** sits behind the settings line: format, rule set (Newest by default), overtime, rounds, each bot's brain (Default by default), dice, hot-seat view, and New seed or Keep this seed. Anything that differs from your last game shows **bold** in the line.
- **The Lineup screen is new.** Each row has one line of numbers (HP, Strength, Range or Reach, Move) and a name button that opens the unit's card. Units the rule forbids are locked. **Pick South lineup** lets you choose the bot's units for that game.
- **Short squads and the checks** (Game Laws 2.2). You can start below your unit cap: the first tap warns, a second tap within 4 seconds starts. Every lineup needs a foot unit. A lineup that breaks a rule can't start, from any path (Lineup, Random, rematch, watch link), and tapping the greyed button tells you why.
- Personality has its sheet (five sliders, 0 to 100, with number boxes). Difficulty, personality, overtime, rounds and dice are saved and shown as "Not built yet". The game ignores them.

**Under the hood**
- `board/squad.js` holds the squad checks: one function, which knows mounted units and Cavalry only from the unit data, ready for Brief 012. `watch.js` adds `squadCounts()` and an optional `squad=` in watch links. A link without one is Open and plays exactly as before. `squad.js` joins the game key.
- The squad rule is saved in the match record (`opts.squadRule`) and shown in Matches. A rematch keeps it and checks both lineups again.
- New tests: `test_squad.js` (the check table, the bot's lineups, bot minimum) and `test_gamestart.js` (the screens in a browser).
